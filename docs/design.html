CUDeck

A lecture-slide theme in the university's identity: a green spine carrying the chapter and how far through it you are, full-bleed dividers, bordered code panels, and type sized for the back row. Eight slides of real teaching material, then the typographic reasoning behind it.

The slides

Eight layouts, and what each is for

Structural slides — the opener and the part dividers — go full-bleed green. Content slides stay white behind a slim green spine carrying the chapter title, a progress bar and the slide number, so a student who looks up mid-lecture knows where they are. Code sits in a panel with a labelled header strip and a line-number gutter you can point at out loud, and the grid lets a listing sit beside what it prints. The panel fill is a pale green-grey with a hairline border, so it reads as an object without a shadow and without ink-heavy fills. Body text is 28 pt and code 18 pt: both survive the back row.

The type

Why Archivo and IBM Plex Mono

Everything shown across both pitches was open-licensed to begin with: Archivo, IBM Plex, JetBrains Mono and Libre Franklin are all SIL Open Font License 1.1, which permits installation, bundling and embedding with no fee and no per-seat limit. What was not open were the fallbacks I listed — Aptos, Calibri, Arial, Segoe UI. Those have to go, and that has one practical consequence, below.

A grotesque drawn for high-performance signage and small screens. The ExtraBold is genuinely heavy, which is what makes B's title slides land. IBM Plex Mono carries the code: a slotted zero, a tailed l, and — the reason it wins here — no ligatures at all, so >= stays two characters on screen.

One superfamily: the sans and the mono share skeletons, widths and metrics, so a variable name in a bullet and the same name in a code panel look like the same word. It is D's own pairing, which makes it the natural choice if the panels are what you liked. Its Bold is lighter than Archivo's ExtraBold — titles lose a little force.

Most coherent. Text and code stop looking like two documents.

A Franklin Gothic revival — an older, warmer American grotesque with more character in the a g R than either of the others. Sets a human-sounding lecture title rather than a systems one. Slightly wider, so long bullet lines run on more.

Most personality. Least neutral, which cuts both ways.

Ligatures off, always

JetBrains Mono ships code ligatures on — it draws >= as a single ≥. Students type two characters, so the deck has to disable them or use the NL cut. IBM Plex Mono has none to disable.

Turkish is covered

All four carry ğ Ğ ş Ş ı İ ö Ö ü Ü ç Ç as drawn glyphs, not composites. Verified on the installed JetBrains Mono; the others ship the same Latin Extended-A set.

The catch: nothing open ships with Windows

Every font preinstalled on a lecture-hall PC is proprietary. Going open-only means the fonts must be installed on whatever machine presents — a one-time copy of four files, but it has to actually happen, or PowerPoint silently substitutes.

Two ways to make that safe

PowerPoint on Windows can embed fonts in the file itself (OFL permits it), which travels. Or export a PDF for teaching and keep the .pptx as the editable master. The second is more reliable and loses the animations — of which these decks have none.

Three things I would like your call on

  1. Which pairing. My recommendation is Archivo for text, IBM Plex Mono for code — B's impact depends on a very heavy headline weight and Plex Sans Bold does not have it, while Plex Mono avoids the ligature problem entirely. Plex Sans throughout is the tidier answer if one superfamily matters more to you than the heavier headline.
  2. Red for mistakes. The identity has only green, black and grey. The "don't do this" panel below uses weight and a rotated marker instead of colour, which is honest to the book but weaker than red on a slide full of C. Worth breaking the palette for, or not?
  3. Deck length. 28 pt body means the operator table and the long traces have to be split across two slides. Chapter 6 goes from 31 slides to roughly 36. Fine, or should body drop to 25 pt to hold the current counts?
